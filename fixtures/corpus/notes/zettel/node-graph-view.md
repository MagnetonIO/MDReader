# Graph View

The graph view draws notes as nodes and links as edges. Wiki-links like the ones
in [[graph-hub]] become edges; broken links (see [[broken-links]]) become
dangling stubs the UI can highlight.

It reads adjacency from [[node-storage]] and colours nodes by tag. Users click a
node to open it in the reader. It pairs with [[node-search]] for "find then
explore". Root: [[graph-hub]].
