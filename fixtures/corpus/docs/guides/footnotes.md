# Footnotes

CatDB stores provenance the way a good essay stores footnotes[^prov]: every
claim can be traced. Vectors are just one representation[^vec], and they are not
always the right one[^vec].

A footnote can hold multiple paragraphs[^long].

[^prov]: Provenance = source file + byte range + ingest run.

[^vec]: Reused reference — the same marker can appear more than once.

[^long]: First paragraph of the long note.

    Second paragraph, indented so it stays part of the footnote. It can even
    contain a [link](task-lists.md).
