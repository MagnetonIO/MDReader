# KaTeX Inline Math

Cosine similarity between vectors $a$ and $b$ is
$\cos\theta = \frac{a \cdot b}{\lVert a \rVert \, \lVert b \rVert}$, which is $1$
when they point the same way and $0$ when orthogonal.

The dot product $a \cdot b = \sum_{i=1}^{n} a_i b_i$ appears inline mid-sentence.

A dollar sign that is *not* math: it costs \$5, and `$PATH` in code is untouched.

Greek and subscripts inline: $\alpha_0, \beta_1, \gamma_{ij}$.

For display math see [the block math note](katex-block.md).
