# Task Lists

Top-level tasks:

- [x] Ship the scaffold
- [ ] Write the ingest
- [ ] Draw the graph view

Nested tasks with mixed state:

- [ ] Release 0.1
  - [x] Fixtures
  - [x] CI
  - [ ] Docs
    - [ ] Getting started
    - [ ] API reference

A task item that also contains a [link](footnotes.md) and `inline code`:

- [ ] Follow up on [footnotes](footnotes.md) once `catdb-query` lands

Not a task, just a bullet that happens to mention "[ ]" in text.
